## B. Informasi Aplikasi
- **Nama Aplikasi:** Aplikasi Kuis
- **Deskripsi Singkat:** Aplikasi kuis interaktif yang menguji pengetahuan pengguna dalam berbagai topik seperti Matematika. Aplikasi ini dilengkapi dengan sistem autentikasi pengguna, pelacakan riwayat skor kuis, serta kostumisasi tema gelap dan terang.
- **Fitur-fitur yang Tersedia:**
    1. Autentikasi Pengguna (Login & Registrasi dengan validasi form).
    2. Bottom Navigation Bar (Beranda, Riwayat, Profil).
    3. Kuis Dinamis dengan tombol navigasi (Kembali & Selanjutnya).
    4. Penyimpanan riwayat skor kuis secara lokal.
    5. State Management menggunakan Provider (Progres tidak hilang).
    6. Dual-Theme (Dark Mode & Light Mode).
    7. Desain Responsif (menyesuaikan ukuran layar).
    8. Dialog Konfirmasi Keluar (Kuis & Logout).
